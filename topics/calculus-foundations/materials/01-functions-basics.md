# Functions, injectivity, surjectivity, bijectivity

Why this material: clean intro to function vocabulary — what a function actually *is*, the difference between injective / surjective / bijective, composition, and inverse. Entry point of the calculus track because every later concept (limits, derivatives, integrals) is a statement about functions.
