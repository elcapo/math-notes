# MIT 18.01 — Lecture 19: First Fundamental Theorem of Calculus

Why this material: the first half of the FTC, $\int_a^b f(x)\,dx = F(b) - F(a)$, which turns the geometric Riemann-sum definition of the integral into a computable object via antiderivatives. This is the payoff that justifies all the algebra of indefinite integrals.
