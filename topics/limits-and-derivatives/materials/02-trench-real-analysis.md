# Introduction to Real Analysis — William F. Trench

Why this material: rigorous reference covering the same content already developed in the topic — ε-δ limits (Ch. 2.1), continuity (Ch. 2.2), and the Fermat → Rolle → Lagrange → Cauchy → L'Hôpital chain with full proofs including the ∞/∞ case (Ch. 2.3). Serves as the canonical text to revisit when reinforcing the formal underpinnings of this topic and as a forward bridge into sequences, series, and multivariable analysis for the UPMC L2 syllabus.

Canonical landing page (with author bio and other formats): https://digitalcommons.trinity.edu/mono/7/
