cf_funcs_01_definition	A machine takes integers and returns 0 if the input is even, 1 if odd. Another machine takes integers and tosses a coin: heads → 0, tails → 1. Both relate inputs to {0, 1}. Which one defines a function, and what property does the other lack?	Only the deterministic machine defines a function. A function must assign <b>exactly one</b> output to each input — combining <b>determinism</b> (same input → same output every time) and <b>uniqueness</b> (one output, not several). The coin-tossing machine fails determinism: the same input can yield different outputs.	functions definition	Basic
cf_funcs_02_dom_codom	The rule "f(x) = x²" alone does not specify a unique function. Why? Give two functions that share that rule but are genuinely different.	A function is specified by its <b>rule + domain + codomain</b>; identical rules over different (co)domains give different functions.<br>Examples: <code>f: ℝ → ℝ</code> is neither injective nor surjective; <code>f: [0, ∞) → [0, ∞)</code> is bijective and invertible. Same formula, different functions.	functions definition	Basic
cf_funcs_03_inj_surj_table	Classify each version of f(x) = x² into one of: <i>injective only</i>, <i>surjective only</i>, <i>bijective</i>, or <i>neither</i>.<br>(a) ℝ → ℝ<br>(b) ℝ → [0, ∞)<br>(c) [0, ∞) → ℝ<br>(d) [0, ∞) → [0, ∞)	(a) <b>Neither</b> — fails injectivity (f(2)=f(−2)) and surjectivity (no preimage of −1).<br>(b) <b>Surjective only</b> — every non-negative is a square; still f(2)=f(−2).<br>(c) <b>Injective only</b> — restricting the domain kills duplication, but ℝ leaves negatives unreached.<br>(d) <b>Bijective</b> — restriction on both sides fixes both flaws.<br><b>Principle:</b> injectivity and surjectivity are independent; tightening domain or codomain toggles each one separately.	functions injective-surjective	Basic
cf_funcs_04_invertibility	Under what condition does <code>f: A → B</code> have an inverse that is itself a function? Justify each half of the condition by saying which property of "being a function" it preserves in f⁻¹.	f must be <b>bijective</b>.<br>• <b>Injectivity</b> of f ⟹ f⁻¹ satisfies <b>uniqueness</b> (each y has only one preimage).<br>• <b>Surjectivity</b> of f ⟹ f⁻¹ satisfies <b>totality</b> (every y ∈ B has a preimage, so f⁻¹ is defined on all of B).<br>Drop either half and f⁻¹ ceases to be a function.	functions inverse	Basic
cf_funcs_05_restriction_principle	To define an inverse for a non-injective function, restrict its domain to an interval that is {{c1::strictly monotonic}} (which gives injectivity) AND {{c2::closed at the endpoints where the function reaches the extremes of its codomain}} (which preserves surjectivity).		functions restriction inverse	Cloze
cf_funcs_06_arcsin_branch	Why is the principal branch of arcsin defined as [−π/2, π/2] and not [0, 2π) or [0, π/2]?	Because [−π/2, π/2] is the unique interval around 0 that is BOTH <b>strictly monotonic</b> (injective) AND <b>closed at both endpoints where sin reaches ±1</b> (surjective onto [−1, 1]).<br>• [0, 2π) fails injectivity — sin(π/4) = sin(3π/4).<br>• [0, π/2] fails surjectivity onto [−1, 1] — image is only [0, 1].	functions restriction arcsin	Basic
cf_funcs_07_composition_noncomm	Let <code>f(x) = x+1</code> and <code>g(x) = x²</code>, both <code>ℝ → ℝ</code>. Compute (g ∘ f)(3) and (f ∘ g)(3). What general property of function composition does this illustrate?	(g ∘ f)(3) = g(4) = 16. (f ∘ g)(3) = f(9) = 10.<br><b>Composition is not commutative</b>: g ∘ f ≠ f ∘ g in general. The inner function transforms the input before the outer one acts, so the order matters.	functions composition	Basic
cf_funcs_08_composition_compat	When is <code>g ∘ f</code> well-defined as a function? Give a concrete example where it fails despite both f and g being valid functions.	Composition requires <b>image(f) ⊆ dom(g)</b>: every output of f must be a legal input of g.<br>Counter-example: <code>f: ℝ → ℝ, f(x) = x − 5</code> and <code>g: [0, ∞) → ℝ, g(x) = √x</code>. Then (g ∘ f)(2) = g(−3), undefined. Composition cannot be formed.	functions composition	Basic
cf_funcs_09_inverse_via_composition	If <code>f: A → B</code> is bijective with inverse <code>f⁻¹: B → A</code>, what are <code>f⁻¹ ∘ f</code> and <code>f ∘ f⁻¹</code>? Why does this give an alternative algebraic definition of "inverse"?	<code>f⁻¹ ∘ f = id<sub>A</sub></code> and <code>f ∘ f⁻¹ = id<sub>B</sub></code>.<br>This turns the pointwise definition ("the function that undoes f") into an <b>equation between functions</b>: f⁻¹ is the unique function whose composition with f (in either order) yields the identity. This formulation generalizes to other algebraic structures (group inverses, matrix inverses, …).	functions inverse composition	Basic
