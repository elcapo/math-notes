cf_funcs_01_definition	A machine takes integers and returns 0 if the input is even, 1 if odd. Another machine takes integers and tosses a coin: heads → 0, tails → 1. Both relate inputs to {0, 1}. Which one defines a function, and what property does the other lack?	Only the deterministic machine defines a function. A function must assign <b>exactly one</b> output to each input — combining <b>determinism</b> (same input → same output every time) and <b>uniqueness</b> (one output, not several). The coin-tossing machine fails determinism: the same input can yield different outputs.	functions definition	Basic	Maths::Calculus Foundations::Functions
cf_funcs_02_dom_codom	The rule "f(x) = x²" alone does not specify a unique function. Why? Give two functions that share that rule but are genuinely different. cf_funcs_08_composition_compat	When is <code>g ∘ f</code> well-defined as a function? Give a concrete example where it fails despite both f and g being valid functions. cf_fams_02_polynomial_degree	A polynomial curve has <b>2 turning points</b> and <b>both ends go to +∞</b>. cf_fams_03_rational_asymptotes	A rational curve f = p/q has a vertical asymptote at x = 3 and a horizontal asymptote at y = 2. cf_fams_06_piecewise_disc_types	A curve is smooth everywhere except at one or two distinguished x-values — that signals <b>piecewise</b>. cf_fams_07_period_invariant	Without invoking the formula T = 2π/b as a charm, derive the period of sin(5x) by applying the invariant "one cycle = the argument has traversed 2π".	One cycle of sin completes when its <b>argument</b> has run through 2π. Here the argument is 5x. For 5x to traverse 2π, x must traverse 2π/5. Therefore <b>T = 2π/5</b>.<br><br>The general invariant: if the argument is bx, every unit of x advances b units of argument; the argument hits 2π when x has advanced 2π/b. The formula isn't memorized — it's read off the invariant.	families trigonometric period	Basic	Maths::Calculus Foundations::Function Families
cf_fams_08_a_c_entanglement	For f(x) = a·sin(b(x − c)) + d, why is the <i>sign of a not recoverable from the graph alone</i>, and what convention resolves the ambiguity?	Because a and c are not independent. cf_fams_09_observation_counting	A function family has k free parameters. Asymptotes pin m of them. You're given N curve points. Under what condition on N are all parameters determined? What if N is smaller — or larger?	After asymptotes, k − m parameters remain. Each point gives one equation, so you need <b>N ≥ k − m linearly independent</b> equations.<br>• <b>N &lt; k − m</b>: <b>underdetermined</b> — infinitely many functions fit; what's left is a (k − m − N)-parameter family.<br>• <b>N = k − m</b>, equations independent: <b>uniquely determined</b>.<br>• <b>N &gt; k − m</b>: <b>overdetermined</b> — only consistent if the extra points agree; they serve as validation, not as new information.<br><br>Caveat: two points carrying the same information do not count as two. The equations must be linearly independent.	families parameter-recovery	Basic	Maths::Calculus Foundations::Function Families
