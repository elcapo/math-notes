iov_ftc_01_exists_vs_closedform	The construction form gives: <b>every</b> continuous f has an antiderivative — yet ∫e^(−x²)dx has <b>no</b> antiderivative in closed form. Why is this not a contradiction?	Two different claims are in play. <b>Existence</b>: G(x) = ∫ₐˣ f(t)dt is well-defined (a definite signed area for each x), and the construction form proves G′ = f, so the antiderivative exists. <b>Closed form</b>: whether that G can be <b>rewritten</b> as a finite combination of elementary functions. The first is guaranteed; the second can fail. "Has an antiderivative" ≠ "the antiderivative is writable in elementary terms".	fundamental-theorem antiderivative closed-form existence	Basic	Maths::Integration of One Variable::Fundamental Theorem
iov_ftc_02_approximation_not_the_test	Tempting claim: "erf(1) = ∫₀¹ e^(−t²)dt has no closed form because we can only approximate its value." Use √2 to show the reasoning is broken.	The reasoning is broken because "having no simple decimal expansion" does not imply "having no closed form". For example, √2 has an exact value and a closed-form expression, even though its decimal expansion is infinite and can only be approximated numerically. Likewise, ∫₀¹ e^(−t²)dt has an exact value regardless of whether it can be expressed in terms of elementary functions or whether we approximate it numerically.	fundamental-theorem closed-form misconception	Basic	Maths::Integration of One Variable::Fundamental Theorem
iov_ftc_03_relative_to_dictionary	In what sense is "has a closed form" <b>not</b> an absolute property of a function? What happens to ∫e^(−t²)dt once erf is admitted into the vocabulary?	Closed form is relative to a <b>chosen dictionary</b> of admitted functions (polynomials, exp, log, trig, roots…). Add erf to that dictionary — exactly as sin and log were once named and tabulated — and ∫₀ˣ e^(−t²)dt = (√π/2)·erf(x) <b>is</b> closed form in the enlarged vocabulary. "Elementary" is a convention about the toolkit, not an intrinsic trait of the function.	fundamental-theorem closed-form convention	Basic	Maths::Integration of One Variable::Fundamental Theorem
iov_ftc_04_nonelementary_is_provable	"∫e^(−x²)dx is not elementary" — is this merely "nobody has found the formula yet", or something stronger? Which classical fact about √2 is the right analogy?	Something stronger: <b>Liouville's theorem</b> proves that <b>no</b> finite combination of elementary functions has derivative e^(−x²). It is a proven impossibility <b>within a fixed dictionary</b>, not a gap in cleverness. The right analogy is "√2 is irrational" — also a proof of non-existence within a fixed system (the rationals), not a number we have failed to write as a fraction. So erf is to the elementary functions what √2 is to the rationals.	fundamental-theorem closed-form liouville	Basic	Maths::Integration of One Variable::Fundamental Theorem
iov_ri_01_refinement	You start with a coarse partition P of [a,b] and compute L(P) = 2.3, U(P) = 4.1. You refine P to P' by bisecting each subinterval. What can you say about L(P') and U(P') relative to 2.3 and 4.1? Explain using the definition of infimum and supremum.	L(P') ≥ 2.3 and U(P') ≤ 4.1. Reason: each subinterval of P' is a subset of a subinterval of P. The infimum over a smaller set is ≥ the infimum over a larger set (fewer candidates, the floor can only rise). The supremum over a smaller set is ≤ the supremum over a larger set. Refinement squeezes L up and U down.	riemann-integral darboux refinement	Basic	Maths::Integration of One Variable::Riemann Integral
iov_ri_02_darboux_criterion_fwd	Suppose for f on [a,b] you can find, for every ε > 0, a partition P with U(f,P) - L(f,P) < ε. Prove f is Darboux integrable on [a,b].	For that P: L(P) ≤ L̅(f) ≤ U̅(f) ≤ U(P), so 0 ≤ U̅(f) - L̅(f) < ε. Since ε is arbitrary, U̅(f) = L̅(f). By definition f is Darboux integrable with ∫f = U̅ = L̅. This is the forward (easy) direction of the Darboux iff criterion.	riemann-integral darboux criterion	Basic	Maths::Integration of One Variable::Riemann Integral
iov_ri_03_darboux_criterion_rev	f is Darboux integrable on [a,b] with integral I. For a given ε > 0, construct a partition P such that U(P) - L(P) < ε.	Since L̅ = U̅ = I, choose P₁ with L(P₁) > I - ε/2 (by definition of L̅ as supremum) and P₂ with U(P₂) < I + ε/2 (by definition of U̅ as infimum). Let P = P₁ ∪ P₂ (mutual refinement). Then L(P) ≥ L(P₁) > I - ε/2 and U(P) ≤ U(P₂) < I + ε/2 ⇒ U(P)-L(P) < ε. This is the reverse direction that makes the criterion a practical test.	riemann-integral darboux criterion refinement	Basic	Maths::Integration of One Variable::Riemann Integral
iov_ri_04_riemann_vs_darboux	Darboux uses inf/sup per subinterval; Riemann uses free sample points. Why does proving Darboux integrability automatically guarantee that <b>every</b> Riemann sum converges to the integral?	For any partition P and any choice of sample points cᵢ ∈ [xᵢ₋₁, xᵢ], the Riemann sum S(P) satisfies L(P) ≤ S(P) ≤ U(P). If refinements make L and U converge (Darboux criterion satisfied), all Riemann sums are squeezed to the same limit regardless of sample-point choice. The Darboux definition eliminates the quantifier over sample points.	riemann-integral darboux riemann-sum equivalence	Basic	Maths::Integration of One Variable::Riemann Integral
iov_ri_05_dirichlet	The Dirichlet function (1 on ℚ, 0 on ℝ\ℚ) is bounded on [0,1] but not Riemann integrable. Which subinterval property causes the failure, and how does the Darboux criterion detect it?	Every subinterval of any partition contains both rationals and irrationals (density of ℚ and ℝ\ℚ in ℝ). So on every subinterval mᵢ = 0 and Mᵢ = 1. Thus L(P) = 0, U(P) = 1 for every partition P. The gap U-L = 1 cannot be made < ε for ε < 1, violating the Darboux criterion. The function is "nowhere locally constant" — it oscillates maximally on every subinterval.	riemann-integral dirichlet pathology	Basic	Maths::Integration of One Variable::Riemann Integral
iov_ri_06_signed_area	The inequality |∫f| ≤ ∫|f| holds for any integrable f. When does equality hold? Give both the analytical condition and the geometric intuition.	Equality holds iff f does not change sign (f ≥ 0 a.e. or f ≤ 0 a.e.). Geometrically: ∫f is signed area (positive and negative parts cancel), while ∫|f| counts all area positively. Algebraically: write f = f⁺ - f⁻; then |∫f| = |∫f⁺ - ∫f⁻| ≤ ∫f⁺ + ∫f⁻ = ∫|f|, with equality iff ∫f⁺ = 0 or ∫f⁻ = 0. This is the integral form of the triangle inequality.	riemann-integral signed-area absolute-value	Basic	Maths::Integration of One Variable::Riemann Integral
