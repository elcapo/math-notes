ld_limits_01_approaching	The limit lim(x→a) f(x) = L means that f(x) approaches L but never reaches L. Why is the detail "never reaches" important?	Because the limit describes the behavior <b>as we get closer</b>, not the value at the point. A function may fail to be defined at a, or be defined but take a different value there. The limit asks: "what value would I pick if I could approach infinitely?" It requires neither x = a nor that f(a) exist.	limits definition	Basic	Maths::Limits and Derivatives::Limits
ld_limits_02_epsilon_delta_order	In the ε-δ definition, why is the order "for every ε there exists δ" and not the other way around?	If we swapped the order ("there exists δ such that for every ε"), we would choose a fixed δ that would have to work for every tolerance. This does not guarantee the relation between closeness to a and closeness to L — it would only succeed if the function were already constant. The correct order says: "<b>whatever</b> tolerance you demand, <b>there exists</b> a distance that meets it." It is a statement of control, not of fixed existence.	limits definition	Basic	Maths::Limits and Derivatives::Limits
ld_limits_03_one_sided_match	A function has a limit at a if its one-sided limits exist AND are equal. Why are both conditions necessary?	If the one-sided limits differ (e.g. a jump discontinuity), the function approaches different values depending on which side we come from — there is no single value of approach, so the limit does not exist. If both are equal, the function approaches the same value from both sides, and that is the limit. The "existence" condition comes first: if one of the one-sided limits does not exist, we cannot compare them.	limits one-sided	Basic	Maths::Limits and Derivatives::Limits
ld_limits_04_indeterminate_means	The expression 0/0 is called "indeterminate", not "undefined". What is the semantic difference between the two?	"Indeterminate" means the expression has no direct answer but <b>can</b> be resolved with further analysis. "Undefined" means it has no solution at all (like ∞ − ∞ in some contexts). 0/0 is indeterminate because the answer depends on <b>which functions</b> produce the zeros — the limit can be 0, ∞, a finite number, or fail to exist.	limits indeterminate	Basic	Maths::Limits and Derivatives::Limits
ld_limits_05_squeeze_principle	The squeeze theorem says: if g(x) ≤ f(x) ≤ h(x) near a, and lim g = lim h = L, then lim f = L. Why does this "trap" work?	The intuition is that f(x) is "trapped" between two functions that converge to the same point L. If both g and h approach L, f has nowhere to escape — it must approach L too. It is like a sandwich: if two walls move toward the same point, any object between them ends up at that point. It does not matter what f(x) does in the interior, only that it is bounded by functions that converge.	limits squeeze	Basic	Maths::Limits and Derivatives::Limits
ld_limits_06_sincos_race	The fundamental limit lim(x→0) sin(x)/x = 1 is proved with the squeeze theorem using cos(x) and 1. Why is cos(x) a good "wall" to trap sin(x)/x?	Geometrically, for 0 &lt; x &lt; π/2, the unit-circle picture shows that sin(x) ≤ x ≤ tan(x). Dividing by sin(x) (positive): 1 ≤ x/sin(x) ≤ 1/cos(x). Taking reciprocals: cos(x) ≤ sin(x)/x ≤ 1. As x→0, cos(x)→1 and 1→1, trapping the quotient between two expressions that converge to 1. The key is that cos(x) is "<b>close to 1</b>" near 0, not "close to 0".	limits squeeze trigonometric	Basic	Maths::Limits and Derivatives::Limits
ld_limits_07_algebraic_fail	The algebraic limit laws (sum, product, quotient) break down when indeterminate forms appear. What mechanism exactly fails in 0/0?	For the quotient, the law says lim f/g = (lim f)/(lim g), but it requires lim g ≠ 0. If lim f = 0 and lim g = 0, the denominator is 0 — we are dividing by something that tends to 0, which has no algebraic meaning. The other laws (sum, product) can also fail because the individual terms have no well-defined limits. The problem is that <b>0/0 is not a number</b> — it is a state that needs more information to resolve.	limits algebraic	Basic	Maths::Limits and Derivatives::Limits
ld_deriv_01_tangent_uniqueness	At a point of a smooth curve (no corners), there is a unique tangent line. What property of the curve guarantees this uniqueness?	The condition is that the function be <b>differentiable</b> (have a derivative) at that point. If there is a corner (like |x| at 0), there are two possible lines that "touch" the curve without crossing it, and neither is more natural than the other. The derivative exists precisely when the limit of the difference quotient converges to a single value — that value is the slope of the unique tangent. If the limit does not exist or yields more than one value, there is no unique tangent.	derivative tangent	Basic	Maths::Limits and Derivatives::Derivative
ld_deriv_02_derivative_limit	The derivative is defined as f'(a) = lim(h→0) [f(a+h) − f(a)]/h. Explain why this limit measures the instantaneous rate of change.	The quotient [f(a+h) − f(a)]/h is the <b>slope of the secant</b> between the points (a, f(a)) and (a+h, f(a+h)). As h→0, the second point moves infinitesimally close to the first, and the secant becomes the tangent. The average rate of change over an interval becomes instantaneous. If h is positive, we approach from the right; if negative, from the left — the limit must agree from both sides.	derivative definition	Basic	Maths::Limits and Derivatives::Derivative
ld_deriv_03_continuity_not_enough	The absolute-value function f(x) = |x| is continuous at 0 but not differentiable there. Explain why the derivative does not exist even though the function is continuous.	At x=0, the graph of |x| has a "<b>corner</b>" — the slope jumps from −1 to +1 instantaneously. From the left: lim(h→0⁻) [f(0+h) − f(0)]/h = lim(h→0⁻) |h|/h = −1. From the right: lim(h→0⁺) [f(0+h) − f(0)]/h = lim(h→0⁺) |h|/h = +1. Since the one-sided limits differ, the two-sided limit does not exist. Continuity only guarantees that the function does not "jump" — it does not guarantee that the slope is consistent.	derivative continuity	Basic	Maths::Limits and Derivatives::Derivative
ld_lhopital_01_when_applies	L'Hôpital's rule applies only to the indeterminate forms 0/0 and ∞/∞. Why not to others like 0·∞ or ∞ − ∞?	The other forms are not quotients — L'Hôpital differentiates numerator and denominator, treating the expression as a quotient of rates of change. For 0·∞ we would first need to rewrite as 0/(1/∞) or ∞/∞, which requires manipulating the expression. For ∞ − ∞ we likewise have to convert the subtraction into a quotient. L'Hôpital is a specific theorem about <b>quotients</b> that yield 0/0 or ∞/∞, not a universal method for any indeterminate form.	lhopital conditions	Basic	Maths::Limits and Derivatives::L'Hôpital
ld_lhopital_02_intuition_why_works	L'Hôpital resolves 0/0 by comparing derivatives. Why are derivatives (rates of change) relevant for comparing how two functions approach zero?	When f(a) = 0 and g(a) = 0 we cannot compare the values at a — both are zero. But we can compare <b>how they leave a</b>: their immediate derivatives. If f' &gt; g' near a, f moves away from zero faster and "wins", so the quotient tends to ∞. If f' &lt; g', it loses. If f' = g', we differentiate again. The derivatives capture the <b>speed</b> with which each function leaves zero, and that speed determines the limit.	lhopital intuition	Basic	Maths::Limits and Derivatives::L'Hôpital
ld_lhopital_03_repeated_apply	For lim(x→∞) x²/eˣ, we apply L'Hôpital twice. Why does a single application sometimes not suffice?	Because the first differentiation can still produce an indeterminate form. Here, x² → ∞ and eˣ → ∞ after the first differentiation (2x/eˣ). Differentiating again (2/eˣ), the numerator becomes a constant (2) while the denominator continues to diverge (eˣ → ∞), so the quotient goes to 0. The rule can be applied <b>recursively</b> until the indeterminacy is resolved. The exponential always eventually "wins" against any polynomial after enough differentiations.	lhopital repeated	Basic	Maths::Limits and Derivatives::L'Hôpital
ld_lhopital_04_caveat_nonexistent	L'Hôpital can fail (give no information) when lim f'/g' does not exist even though lim f/g does. Give a conceptual example.	Take f(x) = x²·sin(1/x) and g(x) = x near 0. Both → 0, so we have 0/0. Then f'(x) = 2x·sin(1/x) − cos(1/x), which oscillates wildly between −1 and 1 (plus a vanishing term). The quotient f'/g' has no limit. But the original quotient f/g = x·sin(1/x) → 0. L'Hôpital fails here: it cannot resolve the limit because the derivative of the numerator does not converge, even though the original limit exists.	lhopital caveat	Basic	Maths::Limits and Derivatives::L'Hôpital
ld_concept_01_bridge	The three concepts (limits, derivatives, L'Hôpital) form a chain: limit → derivative → L'Hôpital. Explain how they connect into a coherent flow.	1) <b>Limit</b> is the foundational language — it defines what "approaching" a value means.<br>2) <b>Derivative</b> is defined as a special limit — the instantaneous rate of change.<br>3) <b>L'Hôpital</b> uses the derivative to resolve limits that are indeterminate forms — it compares rates of change instead of values.<br>The flow: the limit is the base tool, the derivative is a major application of the limit, and L'Hôpital is an application of the derivative that solves limit problems. Each concept builds on the previous one.	conceptual bridge	Basic	Maths::Limits and Derivatives::Conceptual
ld_continuity_01_composition_swap	The theorem "lim f(g(x)) = f(lim g(x))" requires f to be continuous at L = lim g(x). Why does a discontinuity of f at L break this equality?	The left side lim f(g(x)) "sees" the values f takes <b>along the way</b> to L (at points close to but distinct from L). The right side f(L) "sees" the value of f <b>at the destination</b>. Continuity is exactly the condition that says "path and destination agree". Counter-example: if f(x)=1 for x≠0 and f(0)=0, with g(x)=x, then lim f(g(x)) = 1 but f(lim g(x)) = f(0) = 0. The exchange "limit ↔ apply f" is a continuity property, not something automatic.	continuity composition	Basic	Maths::Limits and Derivatives::Continuity
ld_fermat_01_sign_flip	In Fermat's proof (interior local maximum with f'(c) existing), the two one-sided limits of the quotient [f(c+h) − f(c)]/h give inequalities of opposite signs even though the numerator always has the same sign. What mechanism flips the inequality?	The numerator f(c+h) − f(c) is ≤ 0 (c is a local maximum) <b>for both h&gt;0 and h&lt;0</b>. What changes is the sign of the denominator h:<br>- From the right (h&gt;0): negative/positive ≤ 0, so f'(c) ≤ 0.<br>- From the left (h&lt;0): negative/negative ≥ 0, so f'(c) ≥ 0.<br>The hypothesis "f'(c) exists" forces both one-sided limits to agree, and the only way to be simultaneously ≤ 0 and ≥ 0 is to equal 0. All the analytic weight of the theorem lives in this sign-play of the denominator.	fermat derivative extremum	Basic	Maths::Limits and Derivatives::Mean Value Theorems
ld_rolle_01_two_cases	Rolle's proof splits into two cases after applying Weierstrass (existence of a maximum and a minimum). What are they, and in which one is the hypothesis f(a)=f(b) actually used?	<b>Case A — interior extremum:</b> if the maximum or the minimum is attained at some c ∈ (a,b), Fermat gives f'(c)=0 directly. The hypothesis f(a)=f(b) is <b>not</b> used here.<br><b>Case B — both extrema at the endpoints:</b> if the maximum and minimum are attained at a and b, the hypothesis f(a)=f(b) equates them, forcing f to be <b>constant</b> on [a,b] (with value k = f(a) = f(b), not necessarily 0). A constant function has f'(x)=0 at every interior point. Without f(a)=f(b) we could have a monotonic function with distinct boundary values and a derivative that is never zero.	rolle mvt extremum	Basic	Maths::Limits and Derivatives::Mean Value Theorems
ld_lagrange_01_auxiliary	Lagrange's proof applies Rolle to h(x) = f(x) − φ(x), where φ is the chord joining (a, f(a)) and (b, f(b)). Why is h(a) = h(b) = 0, and why is this choice of h no accident?	The chord φ is built <b>precisely</b> to pass through the endpoints: φ(a)=f(a) and φ(b)=f(b) by design. Hence h(a) = f(a) − φ(a) = 0 and h(b) = f(b) − φ(b) = 0. h measures the "vertical gap" between the graph of f and the chord, and that gap is zero at the endpoints because the chord <b>touches</b> f there. Rolle then yields c with h'(c)=0, which (since φ'(x) is the constant (f(b)−f(a))/(b−a)) expands to f'(c) = (f(b)−f(a))/(b−a). The choice of h is not accidental: it is the only natural function whose endpoint values are trivially equal.	lagrange mvt auxiliary	Basic	Maths::Limits and Derivatives::Mean Value Theorems
ld_corollary_01_pointwise_vs_interval	The corollary "f' &gt; 0 on (a,b) ⟹ f strictly increasing on [a,b]" requires f' to be positive throughout the interval. Why is the pointwise version "f'(a) &gt; 0 ⟹ f increasing in a neighborhood of a" false without extra hypotheses?	Monotonicity is an <b>interval</b> property, not a pointwise one. Knowing only f'(a) &gt; 0 at a single point leaves f' free to oscillate between positive and negative values in every neighborhood of a, with no monotonicity for f in any neighborhood.<br>Counter-example: f(x) = x/2 + x²·sin(1/x) (with f(0)=0) has f'(0) = 1/2 &gt; 0, but f' oscillates between positive and negative values in every neighborhood of 0 because of the cos(1/x) term produced by differentiation.<br>The only thing f'(a) &gt; 0 guarantees is a comparison with f(a): f(x) &gt; f(a) for x &gt; a nearby and f(x) &lt; f(a) for x &lt; a nearby — comparison, not monotonicity. Lifting from pointwise to local requires continuity of f' or some additional condition.	derivative monotonicity corollary	Basic	Maths::Limits and Derivatives::Mean Value Theorems
ld_cauchy_01_parametric	Cauchy's MVT says there exists c with f'(c)/g'(c) = [f(b)−f(a)] / [g(b)−g(a)]. What geometric reading generalizes Lagrange if we view (g(t), f(t)) as a parametric curve?	As t runs through [a,b], the points (g(t), f(t)) trace a curve in the xy-plane.<br>- The <b>right side</b> [f(b)−f(a)]/[g(b)−g(a)] is the slope of the <b>chord</b> joining the curve's endpoints.<br>- The <b>left side</b> f'(c)/g'(c), by the chain rule for parametric curves (dy/dx = (dy/dt)/(dx/dt)), is the slope of the <b>tangent</b> to the curve at t=c.<br>Cauchy asserts: there is an interior point where the tangent to the parametric curve is parallel to the chord. It is Lagrange's statement, generalized — Lagrange is the special case g(t)=t (the parametric curve collapses to the graph y=f(x)).	cauchy mvt parametric	Basic	Maths::Limits and Derivatives::Mean Value Theorems
ld_lhopital_05_cauchy_closure	L'Hôpital for 0/0 is proved by applying Cauchy between a and x and then letting x→a. Which two steps make the proof work, and why does neither generalize to the ∞/∞ case?	<b>Step 1 — simplify using f(a)=g(a)=0:</b> Cauchy gives [f(x)−f(a)]/[g(x)−g(a)] = f'(c)/g'(c) with c between a and x. The 0/0 hypothesis collapses the left side to f(x)/g(x). This breaks in ∞/∞: f(a) is not even a finite number to subtract.<br><b>Step 2 — squeeze on c:</b> the c that Cauchy guarantees is trapped between a (fixed) and x (which tends to a), so c→a by the squeeze theorem. Then lim f(x)/g(x) = lim f'(c)/g'(c) = lim f'(x)/g'(x).<br>For ∞/∞ the first step fails, so the result is proved by a different route (a more delicate ε-δ argument, or Stolz–Cesàro), although the conclusion is identical.	lhopital cauchy proof	Basic	Maths::Limits and Derivatives::L'Hôpital
